# Codigos-Python

Uma coleção de códigos em Python, abrangendo desde exercícios práticos até explicações sobre bibliotecas e fundamentos da linguagem.

## Estrutura do Projeto

### Calculadora
Contém implementações de diferentes tipos de calculadoras.

### Credito-Disponivel
Scripts relacionados ao cálculo de crédito disponível.

### Classificando Dados
Contém notebooks para classificação de dados usando bibliotecas como `sklearn`.

- `Classificacao_sklearn.ipynb`: Notebook para classificação de dados usando `sklearn`.

### Criador de Colunas
Scripts para criação de colunas em datasets.

### Listas
Contém notebooks e scripts relacionados a manipulação de listas e algoritmos de busca.

- `Brincnado_com_listasipynb`: Notebook para manipulação de listas.
- `Diferentes-tipos-de-busca.ipynb`: Notebook sobre diferentes tipos de algoritmos de busca.
- `Estudando_While&WhileFor`: Scripts para estudo de loops `while` e `for`.
- `Exercicio de listas.ipynb`: Notebook com exercícios de listas.
- `Oficina_Random_Forest.ipynb`: Notebook sobre Random Forest.
- `Soma_zero&Subsequenica de maior_soma.ipynb`: Notebook sobre soma zero e subsequência de maior soma.

### Quantidade de alunos e turma
Scripts e notebooks relacionados à contagem de alunos e turmas.

### Recursividade
Scripts relacionados a algoritmos recursivos.

- `Binario`: Algoritmos de conversão binária.
- `Contagem Regressiva (maior para o menor)`: Algoritmos de contagem regressiva.
- `Fatorial`: Algoritmos para cálculo de fatorial.
- `Fibonacci`: Algoritmos para cálculo da sequência de Fibonacci.
- `Busca Binária`: Algoritmos de busca binária.

### Relogio
Scripts relacionados à implementação de relógios, contendo 3 formas diferentes para a mesma implementação

### Salario com Bonus
Scripts para cálculo de salários com bônus.
